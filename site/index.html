Built for wallets

Put the same check on your send screen with one function call. You get the verdict, the reason and the fix, ready to show your users.

  • One call: check({ to, from, asset })
  • Runs in the browser or on your server
  • Every address format, smart wallets included
  • Reasons and fixes written for people, not logs
Get the library 
import { check } from "@stellagate/core";

const verdict = await check({
  to: "GDT7ARDYZRBXXYOCSQ3MUMISTITSSRWZI6KR2A5L5Q3KB4QIZHGYMTIH",
  from: userAddress,
  asset: "native",
});

if (verdict.status === "block") {
  const [reason] = verdict.reasons;
  showStop(reason.message, reason.fix);
}

Frequently asked questions

Everything you need to know before your next send.

What does Stellagate check?

Whether the address exists, whether it needs a memo, whether it can hold the asset you are sending, whether your wallet can reach it, and whether it is flagged as a scam. All in one paste.

Do I need to connect my wallet?

No. Paste the address and get the answer. Nothing to connect, nothing to sign.

Does it work with smart wallets?

Yes. Add your smart wallet address and Stellagate tells you whether it can pay that destination, and what to do if it cannot.

Which exchanges does it know?

Every exchange account in StellarExpert's public directory that needs a memo. That is more than a hundred, including Binance, Kraken, Bybit and Coinbase.

What does it cost?

Nothing. Stellagate is free and open source.

Can I add it to my wallet or app?

Yes. The library is open source on GitHub, and one function call runs the whole check.
