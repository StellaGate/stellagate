Memo Lab

Build a memo and check it before it goes out. See how many bytes your text takes, whether an ID fits, and what a valid hash looks like.

1. Memo Text (28-byte UTF-8)

Valid

Stellar restricts text memos to exactly 28 bytes in UTF-8. Non-ASCII characters (accents, umlauts, symbols) consume 2 to 4 bytes each.

2. Memo ID (64-bit Unsigned Integer)

Valid uint64

A memo ID is an unsigned 64-bit integer, from 0 to 18,446,744,073,709,551,615. Negatives, decimals and anything larger fail.

Hexadecimal: 0x0683899d

3. Memo Hash & Memo Return (32-byte Cryptographic Digest)

Valid 32-byte Hash

Used for cryptographic proofs, bridge transfers, and payment returns. Stellar expects exactly 32 bytes (64 hex characters or 44 base64 characters).
